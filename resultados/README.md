# Resultados

Esta pasta contém uma análise didática do crescimento da busca exaustiva em
[analise_crescimento_exaustiva.md](./analise_crescimento_exaustiva.md). Ela usa
somente dados fictícios e não representa o campus. Os resultados finais A1–A5,
o relatório do programa e a recomendação dependem do inventário validado, dos
critérios aprovados e dos tetos de orçamento justificados pelo grupo. Cada
número apresentado no relatório técnico deverá ser reproduzível.
